# مدرستي
نسخة تجريبية عربية RTL لتنظيم محاضرات السادس العلمي.

## النشر
يُنشر الموقع تلقائياً على GitHub Pages عند الدفع إلى فرع main عبر GitHub Actions.
الرابط المتوقع: https://hussein11982.github.io/madrasti/

## ملاحظة
هذه نسخة واجهة تجريبية مستقلة تحفظ بياناتها في LocalStorage في المتصفح. لا تحتاج مفاتيح API أو خادماً. بياناتها لا تتزامن بين الأجهزة، ومسح بيانات المتصفح قد يحذفها.
